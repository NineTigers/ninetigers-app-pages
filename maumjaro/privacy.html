Android 1.0.6(10) 보충 안내 — 2026년 9월 18일

아래 안내는 Android 1.0.6(10) 수정 버전이 제공된 뒤 해당 버전을 사용할 때 적용합니다. iOS 및 아직 업데이트하지 않은 이전 버전의 기능이 이미 변경되었다는 뜻은 아닙니다.

이번 Android 수정 버전부터 새 가상 체험 기록은 체험 시각과 선택한 메모만 저장합니다. 실제 약 이름·용량 입력, 실제 투약 기록의 신규 작성·수정, 투약 알림 제공은 종료합니다. 이전 버전에서 작성한 기록은 원래 내용으로 기기에 보관되며 열람·직접 삭제·암호화 백업과 복원이 가능합니다. 과거 실제 투약 기록을 가상 체험 기록으로 바꾸지 않습니다. 복원한 과거 기록도 새 투약 알림을 만들지 않습니다. 기존 예약 알림은 업데이트 후 앱 실행 시 취소하며, 실패 안내가 표시되면 앱 알림 설정에서 재시도할 수 있습니다. 생활·루틴 알림은 유지합니다. 기존 방침의 기기 내 암호화 저장, 선택형 건강 연동·분석, 삭제 및 백업 안내는 유지합니다. 이 보충 안내는 아직 업데이트하지 않은 이전 버전의 기능이 이미 종료됐다는 뜻이 아닙니다.

v0.11 개정 안내 — 2026년 9월 10일

아래는 v0.11에서 제공할 건강 연동·파일 백업·선택형 앱 이용 분석에 관한 안내입니다. 각 기능이 제공되는 버전에서 해당 기능을 사용할 때 적용합니다. 이 안내의 게시만으로 기존 앱에 분석 기능이 켜지거나 이용자가 동의한 것으로 처리되지 않습니다. 이전 버전에 적용되는 2026년 9월 2일 방침은 아래에 보존합니다.

1. 기기에 보관하는 기록

임인구(Yin-goo Yim, 이하 “개발자”)가 제공하는 마음자로는 회원가입 없는 자기관리 앱입니다. 친구 이름, 생활·투여 기록, 메모와 설정은 기기에 암호화하여 보관하며 개발자 서버나 Google Analytics로 보내지 않습니다. 앱 업데이트 시 기존 기록을 이어서 사용하도록 하며, 앱 삭제·기기 분실·암호화 키 손실 시 복구를 보장하지 않습니다.

2. 건강 데이터 연동

실험실에서 연결을 선택하고 운영체제 권한을 허용하면 Apple 건강 또는 Android Health Connect의 걸음·수면 정보를 읽습니다. Android 건강 연동은 Android 14 이상에서 제공합니다. 미리보기에서 가져오기를 확인한 값은 출처와 함께 기기에 별도로 암호화하여 보관합니다. 연결 중에는 앱을 다시 열 때 허용된 범위에서 갱신할 수 있습니다. 백그라운드에서 지속 수집하거나 원본 건강 앱의 기록을 변경하지 않습니다. 가져온 값은 분석 서비스나 파일 백업에 포함하지 않습니다. 연결 해제·운영체제 권한 철회만으로 기존에 가져온 값이 삭제되지는 않으며, 앱의 건강 데이터 화면에서 별도로 삭제할 수 있습니다. 연결하지 않아도 직접 기록 기능은 사용할 수 있습니다.

3. 기록 백업·복원

사용자가 직접 입력한 기록과 설정을 별도 비밀번호로 암호화한 파일로 저장하고, 비밀번호 확인·미리보기를 거쳐 기존 기록에 병합할 수 있습니다. 자동 서버 백업·동기화는 없습니다. 건강 앱에서 가져온 값, 분석 동의, 기기 암호화 키와 운영체제 권한은 파일에 포함하지 않습니다. iOS는 앱의 Documents/Backups 폴더에 저장하고 운영체제 자동 백업에서 제외합니다. Android는 지원하는 기기 내 저장소에 저장합니다. 사용자가 파일을 다른 위치로 옮기면 해당 위치·서비스의 보관 설정이 적용됩니다. 외부 파일 제공자에서 복원 파일을 선택하면 해당 제공자가 파일을 기기로 내려받을 수 있습니다. 파일·비밀번호 분실이나 손상 시 개발자가 복구할 수 없습니다. 복사한 비밀번호는 기기 클립보드에 담기므로 파일과 따로 안전하게 보관해 주세요.

4. 선택형 앱 이용 분석

대한민국에 거주하는 만 14세 이상 이용자가 앱 이용 분석과 국외 이전에 각각 동의한 경우에만 Google Analytics for Firebase를 이용합니다. 해당하지 않거나 동의하지 않아도 앱 이용에 제한은 없습니다. 생년월일을 받지 않고 연령·거주 해당 확인 답변을 분석으로 보내지 않습니다. 앱 이용 가능 연령은 마켓의 연령 등급을 따르며 분석 동의 조건과 구분합니다.

분석 대상은 앱 실행·온보딩·메뉴 이용·기간 돌아보기·백업/복원 이용 결과, 앱 설치 식별자, 기기·운영체제·앱 정보, 기본 세션 정보와 대략적인 지역입니다. 기능 개선을 위해 사용하며 건강 판단·광고 개인화·계정 동기화에 사용하지 않습니다. 기록 내용·건강 수치·약 이름·투약량· 친구 이름·메모·백업 비밀번호·파일 내용과 경로는 보내지 않습니다. 광고 식별자 수집과 자동 화면 보고는 사용하지 않습니다. SDK가 만드는 기본 이용 정보가 있어 완전 익명 정보라고 안내하지 않습니다.

6. 분석 보관과 철회

사용자·이벤트 수준 데이터의 보관 설정은 2개월이며 새 활동으로 기간을 연장하지 않습니다. 만료 데이터는 Google의 월별 삭제 절차로 처리됩니다. 표준 집계 보고서에는 이 기간이 적용되지 않습니다. 이 설정은 기기의 생활 기록 보관 기간을 제한하지 않습니다. 분석을 끄면 이후 수집을 중단하고 기기에 남은 분석 데이터와 설치 식별자를 초기화합니다. 이미 Google에 전송된 정보가 즉시 삭제되는 것은 아닙니다. Google 보관 설명

7. 스토어 업데이트 확인

배포 앱은 App Store 또는 Google Play의 새 버전 정보를 확인할 수 있습니다. iOS는 공개 앱 ID로 Apple에 조회하고 Android는 Google Play 공식 업데이트 기능을 이용합니다. 생활 기록·건강값·메모·백업 파일을 요청에 넣지 않습니다. 연결 과정에서 제공자가 IP 주소 등 통신 정보를 처리할 수 있습니다. 분석 동의와 별개이며 새 버전 설치는 사용자가 선택합니다.

8. 삭제와 보호

나 돌보기의 기록 전체 삭제는 앱이 관리하는 기록·설정·가져온 건강값·분석 동의 등 로컬 정보를 삭제합니다. 원본 건강 앱 기록, 이미 전송된 분석 정보, 만들어 둔 백업 파일과 다른 위치에 복사한 파일은 함께 삭제되지 않습니다. 백업 파일은 파일 앱 등에서 별도로 삭제해 주세요. 로컬 기록은 운영체제 자동 백업·기기 이전 대상에서 제외하도록 설정합니다. 백그라운드 전환 시 최근 앱 화면의 민감 기록을 가리고 Android의 투여 기록 화면은 캡처를 차단합니다.

개인정보 열람·정정·삭제·처리정지 문의는 ygyim.biz@gmail.com으로 보내주세요. 한국어·영어 문의를 받으며 통상 영업일 3~5일 안에 답변드립니다. 기록 원본이나 백업 비밀번호는 첨부하지 않아도 됩니다. 개발자는 기기 기록에 원격 접근할 수 없으며, 이미 전송된 분석 정보의 요청은 식별·처리 가능한 범위를 확인해 안내합니다. 개별 정보 식별이나 즉시 삭제를 보장하지 않습니다. 마음자로는 의료기기가 아니며 진단·치료·복약 지시를 제공하지 않습니다. 데이터 처리 방식이 바뀌면 본 방침과 마켓의 공개 내용을 갱신합니다.

이전 버전 방침 · 시행일 2026년 9월 2일

임인구(Yin-goo Yim, 이하 “개발자”)가 제공하는 마음자로(이하 “앱”)는 다이어터의 일상적인 자기관리와 생활 습관 기록을 돕는 웰니스 앱입니다.

1. 수집하는 개인정보

현재 버전은 회원가입을 제공하지 않으며, 이름·이메일 주소·전화번호·정확한 위치·광고 식별자나 사용자가 앱에 입력한 생활 기록을 개발자 서버로 수집하거나 전송하지 않습니다.

사용자가 직접 입력한 친구 이름, 아바타·앱 테마 설정, 생활 목표와 알림, 식사·물·움직임·수면·몸·마음 기록 및 자유 메모는 암호화되어 사용자의 기기에만 저장됩니다. 사용자가 선택적으로 관리용 투여 기록을 추가하면 약 이름, 실제 투약량, 단위, 날짜·시간과 메모도 기기에 저장됩니다. 앱은 적정 용량, 증량 단계, 다음 투여일이나 증상을 판단하지 않습니다.

2. 제3자 제공 및 처리 위탁

현재 버전은 개인정보를 제3자에게 제공하거나 처리를 위탁하지 않습니다. 광고, 분석, 구매, 원격 설정 및 충돌 보고 SDK도 사용하지 않습니다.

3. 보관 및 삭제

암호화 파일은 운영체제 백업과 기기 이전 대상에서 제외하도록 설정합니다. 앱을 업데이트하면 기존 기기 기록을 이어서 사용할 수 있습니다. 기기 내 기록과 암호화 키는 사용자가 앱의 ‘나 돌보기 → 기록 전체 삭제’를 두 차례 확인할 때 삭제됩니다. 앱을 삭제하거나 재설치하면 로컬 기록을 복구하지 못할 수 있으며, 다른 기기나 마음자로 서버에서 되찾을 수 없습니다.

앱이 백그라운드로 이동할 때 민감한 기록이 최근 앱 화면에 남지 않도록 가림 화면을 사용합니다. Android에서는 투여 기록 화면의 캡처를 차단합니다.

4. 아동의 개인정보

앱은 아동을 대상으로 개인정보를 수집하도록 설계되지 않았으며, 별도의 연령 정보를 수집하지 않습니다. 이용 가능 연령은 각 앱 마켓에 표시된 연령 등급을 따릅니다.

5. 건강 및 의료 안내

앱은 의료기기가 아니며, 의학적 진단·치료·복약 지시를 제공하지 않습니다. 처방약의 사용·중단·부작용에 관한 판단은 의료 전문가와 상의해야 합니다.

6. 변경

앱의 데이터 처리 방식이 변경되면 본 방침과 각 앱 마켓의 개인정보 공개 내용을 함께 업데이트합니다.
